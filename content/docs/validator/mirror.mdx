---
title: Set weights from our API
description: Read the published vector from the Pareton API and sign it on subnet 10.
---

The simplest way to validate. Read `GET /v1/weights`, sign what it returns,
repeat every 360 blocks.

## Install

```bash
python -m venv .venv && . .venv/bin/activate
pip install bittensor==11.0.2
```

## The vector

```bash
curl -s https://api.pareton.ai/v1/weights
```

```json
{
  "computed_at_block": 6721920,
  "version_key": 2032,
  "burn_uid": 201,
  "weights": [0.0, 0.0, "..."],
  "breakdown": ["..."]
}
```

`weights[i]` is the weight for UID `i`. The list is dense and sums to 1.0.
`breakdown` is the per-campaign audit trail, including the `blocks_held` each
weight was computed at. A 404 means no vector has been computed yet; do not
set anything.

## The script

```python
import json
import urllib.request

import bittensor as bt

NETUID = 10
WALLET = "pareton-validator"
HOTKEY = "default"

with urllib.request.urlopen("https://api.pareton.ai/v1/weights", timeout=20) as r:
    published = json.load(r)

subtensor = bt.Subtensor(network="finney")
wallet = bt.Wallet(name=WALLET, hotkey=HOTKEY)
meta = subtensor.metagraph(netuid=NETUID)

neuron = meta.by_hotkey(wallet.hotkey.ss58_address)
if neuron is None or not neuron.validator_permit:
    raise SystemExit("hotkey is not registered, or holds no validator permit")

weights = [float(w) for w in published["weights"]]
uids = [i for i, w in enumerate(weights) if w > 0]

result = subtensor.execute(
    bt.SetWeights(
        netuid=NETUID,
        uids=uids,
        weights=[weights[i] for i in uids],
        version_key=published["version_key"],
    ),
    wallet,
    wait_for_inclusion=True,
    wait_for_finalization=True,
)
print("ok" if result.success else result.message)
```

Check the permit before you sign. Setting weights without one fails inside the
extrinsic as an opaque substrate error, and the check above names the real
problem instead.

Take `version_key` from the response rather than hardcoding it. If it changes,
your vector still counts.

## Run it on a cadence

Every 360 blocks, about 72 minutes. Compare block heights, not clock time:

```python
head = int(subtensor.block)
if head >= last_set_block + 360:
    ...
```

Keep the process supervised. A validator that stops setting weights stops
earning, and the chain does not warn you. A systemd unit and a `Restart=always`
is enough; see the units in [Run your own
validator](/docs/validator/setup) for the shape.

## Verify a set landed

```python
print(subtensor.query(("SubtensorModule", "Weights"), [10, my_uid]).value)
```

You get `(uid, u16_weight)` pairs quantized against a ceiling of 65535, so they
never match your floats exactly. Compare the ratio between two UIDs, not the
absolute numbers.

Commit-reveal delays the read. Immediately after a set, this correctly returns
your previous vector. Wait a full epoch before you treat it as a failure.

## Failures worth reading

| Symptom                                  | Cause                                          |
| ---------------------------------------- | ---------------------------------------------- |
| `holds no validator permit`              | Your stake is not high enough to keep a permit |
| `is not registered on netuid 10`         | The hotkey lost its UID                        |
| Chain shows the old vector after a set   | Commit-reveal delay. Wait one epoch            |
| Other validators do not trust-weight you | `version_key` does not match                   |
| 404 from `/v1/weights`                   | No vector computed yet. Set nothing            |
